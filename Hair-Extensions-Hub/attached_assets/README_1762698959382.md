# Hair Extensions Hub – Funnel Bundle

This bundle contains ready-to-use pages and assets you can paste into Replit or your current site. It implements the full plan:

- Quiz → Results → $27 Guide → Checkout + Order Bump → Thank You → $97 Upsell
- Shared CSS/JS for a clean look
- Email sequences and ad scripts included in `/assets/content`

## Files
- `/guide.html` — front-offer sales page for the $27 guide
- `/checkout.html` — checkout with order bump
- `/thankyou.html` — post-purchase with upsell prompt
- `/upsell.html` — $97 Salon Vet Pack
- `/confirmation.html` — purchase confirmation
- `/quiz.html` — 60-second pre-qualification quiz (optional entry)
- `/results.html` — shows a simple personalised plan and CTA to the guide
- `/assets/css/style.css` — shared styling (tweak brand colours at top)
- `/assets/js/main.js` — UTM carry + placeholder checkout redirect
- `/assets/content/emails/*.md` — Copy-paste email flows
- `/assets/content/ads.md` — Video scripts and targeting notes

## Integrations
1. **Payments (Stripe/Gumroad):**
   - Replace the `completePurchase()` placeholder in `checkout.html` and `upsell.html` with your real checkout link or embed.
   - If using Stripe Checkout, create a price for the guide and the upsell; redirect success to `thankyou.html` or `confirmation.html`.

2. **Pixels & Conversions API:**
   - Add Meta/TikTok pixel code snippets into `<head>` of each page or via your tag manager.
   - Use the `nav()` function to preserve UTMs across pages.

3. **Email Delivery:**
   - Upload the email markdown files to your email tool (Zoho Campaigns, MailerLite, etc.).
   - Trigger non-buyer series for quiz leads that didn’t purchase; trigger buyer onboarding on purchase.

## KPIs & Rules
- Target LP opt-in ≥ 20% (if sending to quiz) and cold purchase rate 3–8% for the $27 offer.
- Kill ads with CTR < 0.8% (Reels/TikTok) or CPC > $2.50 AUD after ~500 impressions.
- Scale winners +20–30% daily; duplicate with new first 3–5 seconds rather than only raising budget.

## Branding
- Change `--brand`, `--brand-2`, `--brand-3` in `style.css` to your GoAble/Hair Extensions Hub palette.
- Replace copy with your voice and add logos/photos.
